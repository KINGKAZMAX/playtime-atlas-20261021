复刻与原创的边界

参考作品的机制与完成度是学习目标；名称、文案、字体、配色、布局细节与模型形态全部重新设计。本站不声称原创参考作品，也不复制任何未授权 ROM、商业游戏资源或品牌视觉。

案例核验口径

公开帖文的互动量均为 2026-10-21 观测快照。不同平台指标口径不同，不可横向比较或求和；「全网第一」无法证实，本站不作此类声称。

素材来源

全部几何、贴图、字体、图标、封面与音效由代码生成或使用可再分发的开源字体。展品图像为程序化抽象图形，不使用商业游戏截帧。

博物馆收录范围

年代展厅覆盖 1950s 实验电子到 2020s 独立游戏与 VR 的代表性选样，逐条附来源链接，不宣称穷尽任何时代。

研究档案 ≠ 交付清单

「公开案例索引」记录的是研究阶段的候选改编规格（TOP3：NIMBUS·7 / TIDAL DRIFT / HELIOS SPECIMEN）。实际交付的作品是独立重新设计的原创形态，名称与规格均不相同 —— 本站不声称“按 TOP3 复刻”，以各作品自身的说明为准。

试玩说明

作品在站内以 iframe 嵌入运行。首次点击画面后才会激活键盘输入与指针锁定；部分驾驶类作品在嵌套页面中可能被浏览器限制，必要时请「独立窗口打开」。

部署与构建

本站由 GitHub Actions 自动构建并发布到 GitHub Pages。仓库保存全部源码与构建脚本；单件构建失败不会阻断其余作品，并会回退到上一版已验证产物。
