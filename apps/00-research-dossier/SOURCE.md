| 通道 | 用途 | 备注 |
|---|---|---|
| web_search | 广域发现候选 | 多轮以「M3.1 Flash」为唯一主词 |
| `publish.twitter.com/oembed` | 核验作者、正文、发帖日期 | 只证明「作者+正文+日期」，不含互动数 |

| 视频抽帧（ffmpeg） | 逐帧读原帖内演示视频的版式细节 | 仅作**视觉参考**，不复制其中任何素材 |

### 2.2 模型证据（为什么确定是 M3.1 Flash 做的）

证据来自**作者本人在原帖正文中的自述**，不是第三方转述：

1. 明确点名模型：`I asked M3.1 Flash (left) and Opus 5.5 (right) to build me a landing page for a hardware device launch.`
2. 同帖给出同题对照与成本差：`$0.014 vs $1.22`、`4x faster and more token efficient`。
3. 帖内媒体是**同题双版本并排演示视频**（左＝M3.1 Flash，右＝Opus 5.5），两版产出物形态不同，可据画面辨认哪一版属于 M3.1 Flash。
4. 视频中的计数器（token 数与美元成本）在两版间差异显著，与作者所述成本比一致。

> 口径说明：M3.1 Flash 在 2026-09-27 曾以 `M3.1-Flash-Preview` 名义在 Token Plan / MiniMax Code 上线，
> 2026-10-19 正式发布为 **M3.1 Flash**。两者属同一代 M3.1 Flash 家族，不是 M2.x。

### 2.3 可见互动数字与时间
