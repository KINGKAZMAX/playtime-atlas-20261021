## 4. 功能清单（全部为真实功能，无假按钮）

### 4.1 核心操作
- **机台矩阵**：12 台织机，每台独立状态（运行 / 待单 / 换经 / 故障 / 停机），进度条实时推进。
- **实时日志带**：事件流实时滚入（派单、开机、换经、故障、完成、停机），可暂停滚动、可清空、可按级别筛选。
- **任务编排**：手动派单、撤销派单、改优先级、调整订单数量；队列自动补位。
- **实时遥测**：SVG 折线图 + 数字读数（梭速 / 经密 / 张力 / 在织台数 / 断经率 / 能耗）。
- **机台详情抽屉**：点击机台查看该机的订单、进度、经密曲线、事件史。

### 4.2 真实状态反馈（无假按钮）
- 派单 → 订单状态变为「已派往 L-XX」，机台变为「运行」，日志滚入一条，订单簿计数变化。
- 撤销派单 → 订单回到队列队首，机台回到「待单」，日志记录撤销原因。
- 故障 → 织机随机进入故障态，遥测断经率上升，需手动「复位」才能恢复。
- 完成 → 订单状态变为「已完工」，机台自动领取下一单（若无单则转「待单」）。
- 暂停日志 / 清空日志 / 派单 / 撤销 / 复位 / 停机 / 开机 — 每个按钮都有可观察副作用。

### 4.3 表单与异常输入
- **新增订单表单**：布种（枚举）、幅宽（30–120 cm）、经密（20–60 根/cm）、匹数（1–12）、配色（枚举）、优先级。
- 非法输入 → 行内报错并给出具体原因（越界 / 非数字 / 空值），**不写入状态**、不产生日志。
- 派单到不存在的机台、重复派单、超容量 → 明确报错。

### 4.4 键盘操作
| 键 | 作用 |
| --- | --- |
| `1`–`9`, `0` | 聚焦第 1–10 台织机 |
| `↑` / `↓` | 在机台矩阵中上下移动选中 |
| `←` / `→` | 在机台矩阵中左右移动选中 |
| `Enter` | 对选中机台派发队首订单 |
| `Backspace` | 撤销选中机台的当前订单 |
| `Space` | 暂停 / 继续日志自动滚动 |
| `L` | 清空日志 |
| `R` | 复位选中机台的故障 |
| `T` | 切换遥测图表刻度（密度 / 速度） |
| `N` | 聚焦新增订单表单 |
| `Esc` | 关闭抽屉 / 取消选中 |

### 4.5 持久化
- `localStorage` 保存：订单簿、机台状态与进度、日志（上限 200 条）、遥测序列、排产偏好、界面选中态。
- 页面加载自动恢复上次会话（顶部提示「已恢复上次会话 · 时间戳」）。
- 「重置车间」按钮清空存档并回到初始态。
- 存档写入失败（配额 / 隐私模式）时降级为内存态并提示，不静默失败。

### 4.6 响应式
- ≥1280px：三栏（订单簿 / 机台 / 遥测）+ 底部日志带。
- 768–1279px：两栏，遥测移至机台下方。
- <768px：单栏堆叠，机台矩阵转 2 列，遥测图表改横向滚动，触控点按尺寸放大。

## 5. 技术约束

- **不依赖 CDN / 外部 API**：字体、图标、脚本、样式全部本地化；运行时不发起任何外部网络请求。
- **npm 优先**：`package.json` 声明 `dev` / `build` / `preview` / `serve`；`build` 产出纯静态 `dist/`。
- **本地 4313**：`npm run serve` 起本地静态服务器，仅绑定 127.0.0.1。
- **纯前端**：原生 HTML/CSS/JS，无框架运行时；图表用手写 SVG。
