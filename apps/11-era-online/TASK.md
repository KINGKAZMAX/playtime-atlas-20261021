## 4. 展项清单

### 4.1 展项 A —《灯塔协议 / BEACON PROTOCOL》微型策略防守

塔防式格子策略防守，**可完整通关**。

| 系统 | 规格 |
| --- | --- |
| 战场 | 16 × 10 格网，固定蜿蜒路径，路径外可建造，含装饰性岩格 |
| 资源 | 「晶格 Sigma」（击杀/过关获得，用于建造与升级）+「能量 Flux」（随时间回复，仅用于升级） |
| 建造 | 4 种塔，各自 3 级：**脉冲塔 / 霜凝场 / 磁轨炮 / 谐振塔**（数值、射程、目标策略、视觉形态均原创） |
| 升级 | 每塔 Lv1→Lv3，等级以「◆」角标显示；升级改变实际数值（伤害/射速/范围/减速/增益） |
| 出售 | 返还 60% 建造投入 |
| 战斗 | 敌人沿路径推进；塔自动索敌（最前/最近/最强可切换）；有溅射、减速、连锁、增益四类效果 |
| 波次 | 18 波，每 3 波一个**精英波**，第 18 波为「湮灭体」首领；开局前可预览下一波构成 |
| 胜负 | 存活到第 18 波 = **胜利**；灯塔耐久归零 = **失败**；双结局均给出结算面板与统计 |
| AI 对手 | 「灰烬协议」：独立资源池随时间增长，按难度档位周期性向玩家灯塔发动**反向突击**，并用状态文本播报意图；面板常驻「本机 AI · 非真人」标识 |
| 难度 | 谨慎 / 标准 / 激进（改变 AI 资源增速与突击编队强度） |
| 暂停 | `P` 或按钮；暂停时冻结全部模拟并显示遮罩 |
| 保存 | `localStorage` 存档（局面 + 波次 + 资源 + 难度），支持存/读/删，刷新页面不丢 |
| 速度 | 1× / 2× 切换 |
| 操作 | 鼠标点击选格建造；**触屏**：点选塔种按钮 → 点格子建造；**键盘**：`1-4` 选塔种、`↑↓←→` 移动光标、`Enter` 建造/确认、`U` 升级、`X` 出售、`Space` 暂停 |

### 4.2 展项 B —《口袋回声 / POCKET ECHO》掌机风冒险区域

掌机外壳内的可探索冒险，**双屏结构**（上屏画面 / 下屏触摸交互）。

| 系统 | 规格 |
| --- | --- |
| 外壳 | **原创设计**的通用掌机造型（非任何厂商工业设计）：暮港青 + 琥珀色，不含 Logo |
| 上屏 | Canvas 逻辑分辨率 160 × 144，**自绘 5×7 点阵字体**（原创字形表），最近邻放大 |
| 下屏 | DOM 实现的触摸区：对话、菜单、目标、触摸目标选择 |
| 场景 | 3 个可探索区域：**渡口小镇 → 潮汐洞窟 → 灯塔顶台**（含 1 个需要钥匙的封闭区域） |
| 玩法 | 移动、碰撞、拾取「回声碎片 ×3」、与 3 位 NPC 对话、开关机关、躲避洞窟内游荡的「噬潮蟹」、抵达顶台触发结局 |
| 目标 | 集齐 3 枚回声碎片 → 登上灯塔顶台 → 触发结局画面 |
| 失败 | 体力值归零（被噬潮蟹击中扣血）→ 回到渡口小镇起点，碎片保留 |
| 操控 | **触摸**：外壳十字键 + A/B 键 + 下屏菜单点选；**键盘**：方向键/WASD 移动、`Z`=A、`X`=B、`Enter`=Start、`Esc`=暂停 |
| 暂停 | 遮罩 + 菜单（继续 / 存档 / 读档 / 重置） |
| 保存 | `localStorage`：位置、碎片、NPC 旗标、体力 |
| 史料 | NPC 对话内嵌史实短句并附来源链接（掌机与联机服务年代） |

### 4.3 展厅壳层

- **导览**：2000 年代叙事，每段带来源角标。
- **年表**：2000–2009 逐年，每条含「主机 / 掌机 / 联机服务 / 代表作品」四栏 + 来源。
- **展柜**：硬件与服务卡片（纯文字 + 程序化抽象图形，**不使用官方 Logo 与受版权配图**）。
- **史料台账**：全部来源逐条列出（URL / 类型 / 访问时间），并明确「引用 ≠ 授权」。
- **引用高亮开关**：一键显示/隐藏所有来源角标，便于核对。
- **无障碍**：2D 目录视图、键盘可达、`aria-label`、对比度 ≥ 4.5:1、`prefers-reduced-motion` 降级。

## 5. 史料来源纪律

1. 每条历史陈述**至少挂 1 个来源角标**，角标链接到可访问 URL。
2. 来源分级标注：
   - `官方` — 厂商官网/新闻稿
   - `百科` — 维基百科（次级源，用于交叉核对）
   - `本厅` — 本展厅原创设计值
3. 所有链接在交付前做过 HTTP 可达性抽样验证，结果记入 `QA.md`。
4. **明确限制**：本展厅只做**代表性选样**，不宣称覆盖该时代全部作品；未联网抓取的厂商视觉资料不作为事实依据。

## 7. 验收标准

1. `npm run dev` / `npm run build && npm run preview` 均在 `127.0.0.1:4331` 可访问，控制台无报错。
2. `npm run build` 产物 `dist/` 内为**相对路径**引用，置于任意子目录均可正常加载。
3. 展项 A：能建造 4 种塔、升级到 3 级、资源随击杀增长、暂停/继续正常、存档刷新后仍在、可通关（胜利）与失败两条结局均可达成。
4. 展项 A：AI 对手面板常驻「本机 AI」标识，且反向突击真实发生（能在 HUD 看到 AI 意图与突击事件）。
5. 展项 B：3 枚碎片可拾取、可与 NPC 对话、可通关、可被击中扣血、可暂停与存读档。
6. 两个展项均可用**纯触屏**完成核心操作（不需要鼠标精确悬停）。
7. 两个展项均可用**纯键盘**完成核心操作。
8. 展厅页所有历史陈述带来源角标；「史料」区列出全部 URL。
9. 全站无任何「多人在线 / 联网对战」误导性表述；相关表述均带明确否定或限定。
10. 桌面 1280×800 与移动 390×844 两种视口下布局不溢出。
11. `manifest.json` 字段齐全，`status` 反映真实完成度。
