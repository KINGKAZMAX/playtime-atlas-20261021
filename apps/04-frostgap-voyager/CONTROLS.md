# 操作说明 · CONTROLS

《霜隙远航 · Frostgap Voyager》

---

## 一、基础操控

飞船是 **6 自由度** 的：横滚、俯仰、偏航三个姿态轴与前后、左右、上下三个平移轴互相独立。

### 姿态（转向）

| 按键 | 作用 |
| --- | --- |
| **鼠标上下移动** | 俯仰（抬头 / 低头） |
| **鼠标左右移动** | 偏航（左右转向） |
| **Q** | 向左滚转 |
| **E** | 向右滚转 |
| **方向键 ↑↓** | 俯仰（纯键盘备用） |
| **方向键 ←→** | 偏航（纯键盘备用） |

### 平移与推进

| 按键 | 作用 |
| --- | --- |
| **W** | 向前推进（沿机头方向） |
| **S** | 向后推进（反推） |
| **A** / **D** | 向左 / 向右平移 |
| **Space** | 上升 |
| **Ctrl** / **C** | 下降 |
| **Shift** | 后燃器推进（前向推力 ×5.2，消耗燃料） |
| **X** / **B** | 刹停（反推抵消当前速度） |

> 推进器**只给加速度，不会自动减速**。松手后飞船保持惯性漂移，这是太空飞行的基本手感。
> 需要停住时用 `X` 刹停，或在暂停菜单里打开「飞行辅助」获得轻微自动阻尼。

### 视角与系统

| 按键 | 作用 |
| --- | --- |
| **F** | 扫描准星指向的天体 |
| **R** | 与灯塔站对接 / 脱离泊位 |
| **M** | 打开星图并跃迁 |
| **Tab** | 移动键盘焦点（**不劫持**浏览器默认行为）。菜单里在按钮间遍历；飞行中把焦点放到驾驶舱画面上，画面会出现金色焦点环 |
| **V** | 座舱视角 ⇄ 追尾视角 |
| **H** | 打开操作说明 |
| **Esc** | 暂停（并解除鼠标锁定） |
| **Backspace** | 重置飞船姿态与位置 |

## 二、指针锁定失败怎么办

点击画面会尝试锁定鼠标指针。如果浏览器拒绝（例如内嵌页面、权限策略、或用户按了 Esc），
游戏**不会卡住**：

1. 画面中央会出现「点击画面 · 锁定鼠标以驾驶」提示，随时可再次点击锁定；
2. 未锁定时，**按住鼠标左键拖拽**同样可以转向；
3. **方向键**始终可以俯仰与偏航；
4. 所有推进、滚转、扫描、对接键位在两种模式下完全一致。

## 三、一次完整航程

1. **接管霜隙号** — 在主菜单点「接管霜隙号」，点击画面锁定鼠标。
2. **脱离泊位** — 按 `R` 离开灯塔站的 04 号泊位。
3. **离开灯塔站 6 公里** — 按住 `W`，必要时用 `Shift`。
4. **加速到 400 m/s** — 按住 `W` + `Shift`（后燃器会明显提速并消耗燃料）。
5. **扫描维岚** — 把准星对准气态巨行星「维岚」，按 `F`。扫描 2.6 秒后写入远航档案。
6. **跃迁到碎屑回廊** — 按 `M` 打开星图，选「碎屑回廊」，点「执行跃迁」。
7. **扫描异常体** — 在回廊里找到发光的异常体（例如「空心骨」），对准后按 `F`。
8. **扫描霜隙** — 再次打开星图，跃迁到「霜隙环系」，对准带环冰巨星按 `F`。
9. **返航补给** — 回到灯塔站附近，把速度降到 300 m/s 以下，对准泊位导引灯按 `R`。
   对接后燃料加满、船体修复。

## 四、速度与距离

- 画面右下角（仪表台右侧）是当前速度，单位 **m/s**。
- 顶部右侧读数塔显示：最近目标、泊位距离、已归档数量、航向、驾驶模式。
- 底部仪表台从左到右：推进、燃料、船体、扫描进度、速度。
- 仪表台左侧的矩形屏幕是 **MFD 主显示器**（姿态仪 / 雷达 / 状态），
  右侧的**圆形 CRT** 是罗盘 / 侧滑 / 升降速度副显。

## 五、危险提示

| 提示 | 含义 |
| --- | --- |
| 接近维岚地表 | 距地表不足 12 km，继续前进会撞击 |
| 进入维岚大气层 · 过热警告 | 船体开始积累热量并产生阻力，速速离开 |
| 撞击维岚地表 · 船体受损 | 已发生碰撞，船体耐久下降 |
| 燃料不足 | 后燃器快没油了，回灯塔站对接补给 |
| 船体损毁 | 耐久归零，飞船被拖回灯塔站并扣除 150 信用点 |

## 六、设置

暂停菜单（`Esc`）里可以调整：

| 设置 | 说明 |
| --- | --- |
| 画质 | 低 / 中 / 高，切换后重建天体系统（需要一两秒） |
| 音量 | 主音量 |
| 鼠标灵敏度 | 0.20 – 2.50 |
| 视场角 FOV | 55° – 105° |
| 反转 Y 轴 | 鼠标俯仰方向反转 |
| 飞行辅助 | 松杆时的轻微自动阻尼（默认开启） |
| 静音 | 一键静音 |
| 语言 | 中 / EN 切换（同一个切换控件也在主菜单底部） |

设置、发现记录与任务进度都保存在浏览器 `localStorage`，刷新页面不会丢失。

## 七、语言

- 界面文案、任务链、区域与天体名、星图与远航档案全部提供**中英双语**。
- 切换控件在**主菜单底部**与**暂停设置面板**内（`中` / `EN` 两个 chip）。
  放在对话框内部是刻意的：浮层遮罩铺满全屏，浮在视口角落的按钮会被盖住而点不到；
  而飞行中指针被画布锁定，角落控件本就点不到。
- 切换后：`<html lang>` 随之改变、`hreflang` 自动重写、语言偏好写入
  `localStorage['frostgap-voyager.lang.v1']`，刷新后仍生效。
- 也可以直接用地址参数直达：`?lang=zh-CN` / `?lang=en`。
