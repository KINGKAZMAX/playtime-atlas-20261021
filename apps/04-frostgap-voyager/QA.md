## 一、怎么跑验收

### 1. 一键自验（构建 + 临时静态服务器 + 定向复核）

```bash
bash scripts/verify.sh
```

流程：`npm run build` → 在 `127.0.0.1:4321` 启动临时静态服务器 → 跑 `qa/verify-fixes.mjs`
→ 脚本退出时 `trap` 立刻关闭服务器（**不留常驻进程**）。

### 2. 完整功能回归（39 项断言 + 实机截图）

```bash
npm run start          # 另开一个终端：启动 127.0.0.1:4314
node qa/qa.mjs         # 产出 qa-report.md / qa-report.json / screenshots/
```

需要 Playwright：`npm i -D playwright`，或用 `QA_PLAYWRIGHT=/abs/path/to/playwright/index.mjs`
指定已有安装。默认使用系统 Chrome 通道（可调用真实 GPU）。

### 3. 监工 harness 复跑（只读复用，不修改）

```bash
cd ../13-qa-curation/qa-harness
node run-qa.mjs --target=04-spaceflight
```

> 关于速度读数的浮动：飞行模型是**固定 1/120 s 步长累加器**，单帧最多推进 8 个子步
> （约合 15 fps 的下限）。当机器被其它任务压满时，实际推进的模拟时长会短于墙钟时长，
> 因此不同批次跑出的绝对速度值会有差异（例如后燃器峰值 11 ~ 25 u/s），
> 但**趋势与判定（推进/提速/减速的相对关系）始终稳定**。这是防止「死亡螺旋」
> 的有意设计，不是缺陷。

### 验收脚本的两处加固

为了让验收在**被其它任务压满的机器**上也能稳定复现，本轮对 `qa/` 下两个脚本做了加固：

1. **点击改用真实鼠标手势**（`page.mouse.click` + `boundingBox`），不再用 `page.click`。
   `page.click` 在动作完成后还要等待「计划中的导航结束」，当渲染进程被拖慢时这一步会
   耗尽整个动作超时并报 `Timeout ... waiting for scheduled navigations to finish`——
   但点击其实已经生效。`page.mouse.click` 派发同样的受信输入事件
   （指针锁定、点击处理器都照常工作），却不参与导航等待。
2. **异常路径必定回收浏览器**：`try/finally` 关闭 browser，`SIGINT`/`SIGTERM`/`exit`
   处理器兜底，避免在高负载机器上留下孤儿 Chrome 进程。

这两处只改动验收脚本，**不涉及产品代码**。

## 四、已知限制

1. **尺度为游戏性压缩**：1 世界单位 = 100 米。行星半径 800 单位（80 km）远小于真实行星，
   目的是让 10–30 km 级星区能在 1–2 分钟内穿梭，同时保留视觉上的"巨型"感受。
   角尺寸只取决于距离/半径比，所以看起来仍然是庞然大物。
2. **美术为程序化抽象**：行星表面是噪声合成的色带与陨坑图案，不是真实地质纹理；
   没有 PBR 贴图、没有法线贴图、没有外部 HDRI。
3. **无外部音景**：全部音效由振荡器与噪声合成，缺少真实飞船的环境录音质感。
4. **无触控操控**：仅支持键鼠。移动端只能浏览菜单，无法驾驶（已由监工 harness 的
   D2 mobile 检查确认布局不破版）。
5. **无多人、无联网、无排行榜、无账号**：进度仅保存在本机浏览器，换浏览器即丢失。
6. **指针锁定在部分内嵌环境不可用**：已实现拖拽 / 方向键回退，但回退模式下转向手感略逊。
   另：浏览器在指针锁定时把第一次 `Tab` 送去自己的界面栏并顺带丢掉锁定，
   因此飞行中由游戏接管 `Tab`（焦点落在驾驶舱画面上，锁定不丢）；菜单里仍用浏览器原生遍历。
7. **低画质档会关闭 Bloom 与体积星云壳**，视觉层次不如高档；软件光栅器会被强制降档。
8. **画质切换会重建整个天体系统**，过程中有 1–2 秒轻微卡顿。
9. **碰撞体是近似的**：行星用球体、空间站用球体 + 环面近似、空间站旋转环用固定朝向近似，
   在环边缘高速穿过时可能出现轻微穿模。
10. **未做手柄支持**（Gamepad API 未接入）。
11. **13-qa-curation 的目标注册表仍登记改名前的作品名**，本次未修改该目录（只读复用），
    页面自身标题、manifest 与文档均为现行名。
12. **保留了两个旧的技术标识**（非用户可见文案，属于与监工 harness 的接口契约）：
    `window.__deepSpaceDrifter`（游戏实例调试句柄）与
    `localStorage` 的 `deep-space-drifter.save.v1` / `deep-space-drifter.settings.v1`。
    监工 harness 的 `lib/probes.mjs` 直接按这两个名字读写状态与存档；
    若改名，harness 的 D3 / D4 判定会立刻失败。玩家在开发者工具里看到旧前缀属于预期，
    与作品名、界面文案、字体、配色、布局、模型形态无关。
13. **不分发 CJK 字体子集**：字体栈保留 `"Noto Sans SC"` 族名，但本包只含三个拉丁字族
    （Space Grotesk / Inter / Space Mono，均 OFL-1.1）。中文在未装 Noto Sans SC 的系统上
    回退系统黑体（PingFang SC / 微软雅黑 / Hiragino）。原因见 `LICENSES.md` §3.1：
    16 提供的 CJK 子集覆盖不全，会导致同句混排。
14. **语言切换控件放在对话框内部**（主菜单卡 / 暂停设置卡各一枚），而不是浮在视口右上角：
    浮层的遮罩铺满全屏，角落的 chip 会被盖住而点不到；飞行中指针被画布锁定，角落控件
    本就点不到。放进对话框后既不会被遮罩盖住，也在焦点陷阱内、键盘可达。
    代价：飞行中若想换语言，需先按 Esc 打开暂停面板。
15. **英文为次要语言**：界面文案、任务链、区域与天体名、星图与档案均已双语化；
    但任务/天体/区域的英文名是**新写的对译**，不是官方译名，语域偏「航行日志」体。
    中文仍是主语言，默认启动语言为中文。
