# TASK 04 —《霜隙远航 · Frostgap Voyager》

第一人称 3D 飞船驾驶游戏。全部代码原创手写，Three.js + Vite 本地工程，运行时不依赖任何 CDN / 在线 API。

> 作品名与全部文案在开发中期按「重新设计、不做复刻」的要求做过一次整体改版：
> 初版名为「深空漫游 / Deep Space Drifter」，现行为**《霜隙远航 · Frostgap Voyager》**。
> 改名与差异对照见 [SOURCE-AND-DIFFERENCES.md](SOURCE-AND-DIFFERENCES.md)。

## 2. 功能需求清单

### 2.1 飞行操控（真正的 6 自由度）
- 鼠标俯仰（pitch）/ 偏航（yaw）
- `Q` / `E` 滚转（roll）
- `W`/`S` 前后推进，`A`/`D` 左右平移，`Space`/`Ctrl` 升降
- `Shift` 后燃器推进（消耗燃料）、`X`/`B` 刹停
- `Esc` 暂停 + 解除指针锁定；`Backspace` 重置；`H` 说明
- 牛顿惯性 + 可选飞行辅助；**帧率无关**（固定步长 1/120 s 累加器）
- **指针锁定失败时仍可操作**：拖拽转向 + 方向键转向 + 全键盘

### 2.2 视觉
- 电影感驾驶舱：切角八边形舷窗框、楔形重檐 + 铆钉条、罩檐式 MFD、圆形 CRT 副显、
  三枚指示表、角状侧控制台、扳机握把、投影 HUD
- 巨型带大气行星（双层壳边缘辉光）、带环行星（程序化环带 + 卡西尼缝 + 行星阴影）、
  恒星（米粒组织 + 临边昏暗 + 日冕）、星云、实例化小行星带、空间站（泊位导引灯 + 光束）

### 2.3 游戏性
- 从驾驶舱起飞 → 自由探索 **4 个区域**（维岚轨道 / 碎屑回廊 / 霜隙环系 / 伊尔达星域）
- 星图选择目标 → 跃迁（弯曲航线 + 屏幕空间拉丝 + 音效）
- 扫描天体（2.6 s、扫描结果弹窗、档案归档）
- 靠近灯塔站完成**对接 / 补给**
- 教程引导、8 段任务链、发现记录（localStorage 持久化）
- 画质设置、静音开关、指针锁定失败回退

### 2.4 安全与反馈
- 行星碰撞 / 近地限制（推回 + 损伤 + 警告）、大气过热与阻力
- 空间站核心与旋转环碰撞、小行星碰撞、异常体碰撞
- 速度、距离、航向、高度、燃料、船体耐久实时反馈
- 目标菱形标记（可扫描 / 已归档 / 引导中三种状态色）、扫描进度环

### 2.5 音频
- WebAudio **程序化合成**（无音频文件）：引擎低频轰鸣、后燃器噪声、风噪、大气轰鸣、
  UI 提示音、扫描蜂鸣、跃迁充能/跳跃、停靠提示音、碰撞闷响、任务完成和弦
- **必须用户点击后启动**；支持音量与静音

## 4. 验收标准（自测）

1. `npm run build` 产出 `dist/index.html`，退出码 0
2. 浏览器打开可进入游戏；鼠标俯仰偏航真实改变姿态；`Q`/`E` 滚转生效
3. `Shift` 加速且燃料下降；`X` 刹停能在数秒内把速度压到接近 0
4. `Esc` 暂停并解除指针锁定；**继续之后再次按 `Esc` 仍能打开暂停面板**
5. `M` 打开星图，选目标跃迁，位置真实改变且有跃迁特效
6. `F` 扫描目标，完成后进入发现记录（刷新页面仍在）
7. 靠近灯塔站按 `R` 对接成功并补给燃料
8. **连续按 `Tab` 时焦点在可聚焦元素之间移动，且聚焦元素有可见焦点环**
9. 控制台无报错；`localStorage` 有存档
10. 零跨域请求；可在子路径下正常加载

## 5. 已知取舍

- 采用「1 世界单位 = 100 米」的压缩尺度：保证 10–30 km 级星区可在一两分钟内穿梭，
  同时保留行星的**视觉**巨大感（角尺寸只取决于距离/半径比）。
- 行星/恒星/星云全部为程序化生成的美术，不是照片级 PBR；追求「电影感剪影 + 体积辉光」
  而非写实材质。
