## 2. 功能需求清单

### 2.1 飞行操控（真正的 6 自由度）
- 鼠标俯仰（pitch）/ 偏航（yaw）
- `Q` / `E` 滚转（roll）
- `W`/`S` 前后推进，`A`/`D` 左右平移，`Space`/`Ctrl` 升降
- `Shift` 加力推进（afterburner，消耗燃料）
- `X` / `B` 刹车
- `Esc` 暂停 + 解除指针锁定；`R` 重置姿态；`H` 帮助
- 牛顿惯性 + 可选飞行辅助；**帧率无关**（固定步长累加器）
- **指针锁定失败时仍可操作**：拖拽转向 + 方向键转向 + 全键盘

### 2.2 视觉
- 电影感驾驶舱：真实可见的舷窗框（带厚度的挤出几何）、仪表台、MFD 屏幕、侧控制台、投影 HUD
- 巨型带大气行星（大气边缘辉光着色器）、带环行星（程序化环带 + 卡西尼缝）、恒星（米粒组织 + 日冕）、星云（程序化 fbm）、小行星带（实例化）、空间站（程序化模块 + 泊位导引灯）、尺度感

### 2.3 游戏性
- 从驾驶舱起飞 → 自由探索 **≥3 个区域**
- 星图选择目标 → 跃迁（warp，含视觉/音效）
- 扫描天体（扫描进度、扫描日志）
- 靠近空间站完成**停靠 / 补给**
- 教程引导、任务进度、发现记录（localStorage 持久化）
- 画质设置、静音开关

### 2.4 安全与反馈
- 行星碰撞 / 近地限制（推回 + 损伤 + 警告）
- 大气层阻力与过热警告
- 空间站核心碰撞、小行星碰撞
- 速度、距离、高度、燃料、船体完整度实时反馈
- 目标方位指示器、扫描环、停靠提示

### 2.5 音频
- WebAudio **程序化合成**（无音频文件）：引擎低频轰鸣、推进器噪声、UI 提示音、扫描蜂鸣、跃迁轰鸣、停靠提示音、碰撞闷响
- **必须用户点击后启动**（AudioContext resume）
- 静音开关

## 4. 验收标准（自测）
1. `npm run start` 后浏览器打开 `http://127.0.0.1:4314` 可进入游戏
2. 鼠标可俯仰偏航，飞船真实位移；`Q`/`E` 可看到地平线旋转
3. `Shift` 加速且燃料下降；`X` 刹车能在数秒内把速度压下来
4. `Esc` 暂停并解除指针锁定，恢复后继续
5. `M` 打开星图，选目标跃迁，位置真实改变且有跃迁特效
6. `F` 扫描目标，完成后进入发现记录（刷新页面仍在）
7. 靠近空间站按 `R` 停靠成功并补给燃料
8. 控制台无报错；`localStorage` 有存档

## 5. 已知取舍（进行中）
- 采用「1 世界单位 = 100 米」的压缩尺度：保证 10–20 km 级星区可在一两分钟内穿梭，同时保留行星的**视觉**巨大感（角尺寸只取决于距离/半径比）。
- 行星/恒星/星云全部为程序化生成的美术，不是照片级 PBR；追求"电影感剪影 + 体积辉光"而非写实材质。
