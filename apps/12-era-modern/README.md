# 折光纪 · 当代可玩展厅 / PRISM ERA

> 回响电玩馆（PLAYTIME ATLAS）· **modern（2015–2026）时代展厅**
> 三件可玩展品：节奏反应 · 空间解谜 · 桌面端沉浸观景台

本目录是一个**独立、可静态部署**的子展厅。全部作品名、文案、音乐、视觉、关卡均为原创；
参考的是公开作品成熟的机制与品质标准，**不声称原创任何参考作品**，不使用任何未授权 ROM、
商业游戏资源或品牌视觉。

---

## 1. 快速开始

```bash
cd 12-era-modern
npm install          # 依赖全部本地安装，运行期零 CDN
npm run dev          # 开发服务器  http://127.0.0.1:4332
npm run build        # 静态产物   →  dist/
npm run preview      # 预览产物   http://127.0.0.1:4332
npm run start        # 一键：安装依赖 + 启动开发服务器
```

其它命令：

```bash
node scripts/test-levels.mjs   # 关卡自检：验证 4 关均可用作者解法点亮全部接收环
```

**部署形态**：`vite.config.js` 中 `base: './'` + 哈希路由（`#/pulse` 等），
因此 `dist/` 可以直接放在任意静态目录或子路径下（GitHub Pages 的 `/<repo>/<subdir>/` 亦可），
**无需服务端重写规则**。

## 2. 三件展品

### 2.1 《脉冲走廊 / PULSE CORRIDOR》— 节奏反应

四轨光带从远处滑来，节拍与手指对撞。三首曲目全部由 WebAudio **实时合成**（无音频文件），
**谱面即乐谱**：每个音符既是判定点也是主旋律的一个音，因此视听天然对齐、不会漂移。

| 曲目 | BPM | 难度 | 特点 |
| --- | --- | --- | --- |
| 启明 / FIRST LIGHT | 100 | 入门 | 四分音符双向级进 |
| 潮汐 / TIDE GLASS | 124 | 进阶 | 切分与八分音跑动 |
| 棱镜风暴 / PRISM STORM | 150 | 挑战 | 十六分音簇 + 反应事件 |

**三种模式**
- **谱面模式 CHART**：跟随主旋律敲击轨道，判定准度、连击与评级（S/A/B/C/D）。
- **反应训练 REACTION**：只做反应，统计中位 / 最快 / 最慢反应时。
- **混合模式 HYBRID**：谱面中穿插「应答靶」（出现后必须按对应轨道）与「禁触靶」（不得按下）。

**静音视觉替代（硬性要求，已实现）**
- 开启「视觉节拍模式」后**完全不产生任何声音**：不创建 AudioContext，节拍改由
  **收缩节拍环 + 下行节拍光带 + 顶部拍点标尺 + 轨道行亮度脉冲**表达。
- 游戏时钟统一走 `performance.now()`，音频只是可选呈现层，
  因此**静音模式与有声模式的判定精度完全一致**（验收记录见 `QA.md`）。
- 轨道用**形状标识**（◆ ● ▲ ■）区分，兼容色觉障碍；另提供高对比与减少动效开关。

**操作**：`D F J K` / `← ↓ ↑ →` / 触屏点按 · `Esc` 暂停 · `R` 重开 · `M` 静音（设置面板内）

### 2.2 《折光阁 / PRISM ATRIUM》— 空间解谜

等距 3D 玻璃中庭。转动反光板，让白光在立柱之间折返、劈成青与品红，分别落进接收环。

**元件与规则（原创）**

| 元件 | 作用 |
| --- | --- |
| 光源塔 emitter | 定向发射指定颜色的光 |
| 反光板 mirror | 两向反射（`/` 与 `\`），可旋转 |
| 分光镜 splitter | 一束变两束：直行 + 指定方向分叉 |
| 色散棱镜 dispersion | 白光裂成青 + 品红，分别射向两个方向 |
| 接收环 receiver | **颜色必须匹配**才会点亮；不匹配会给出「色不符」提示 |
| 光栅门 gate | 挡光挡人，由余辉压板供电 |
| 余辉压板 plate | 踩下后维持 15 秒开启（制造时间压力） |
| 移动浮台 platform | 往返移动并载行玩家 |
| 光点 mote | 可选收集，影响星级 |

**四个关卡**

| 关 | 名称 | 机制重点 | 接收环 |
| --- | --- | --- | --- |
| LV1 | 回廊 CORRIDOR | 移动 + 旋转反光板 | 1 |
| LV2 | 分流 FORK | 色散、分光、颜色匹配 | 3 |
| LV3 | 时序 CADENCE | 光栅门 + 余辉压板 + 移动浮台 | 1 |
| LV4 | 合奏 CHORUS | 三光源 / 三棱镜 / 门与压板 | 4 |

**进度与工具**：通关记录、最佳用时、星级、光点数量自动存本机（localStorage）；
可随时 **撤销 / 提示 / 重置**。提示基于关卡作者预设的推荐朝向（UI 已注明这一点）。

**操作**：`WASD` / 方向键移动 · 点击元件或 `E` 旋转 · `Tab` 切换目标 · 拖拽旋转视角 · 滚轮缩放

### 2.3 《光环台 / HALO DECK》— 沉浸展项（桌面交互演示）

> ⚠️ **诚实声明**
> 本展项是**桌面端交互演示**：用鼠标拖拽与键盘模拟头部转动，
> **未接入 WebXR、不支持 VR 头显**，没有立体渲染，也没有手柄追踪。
> 它演示的是「沉浸式展陈的交互模型」，**不是** VR 应用。
>
> 展台提供「检测本机 WebXR 沉浸式 VR 支持」按钮，结果直接来自浏览器
> `navigator.xr.isSessionSupported('immersive-vr')` 的真实返回值，与本展项的实现无关。
> 真正的设备支持需要按 [W3C WebXR 规范](https://www.w3.org/TR/webxr/) 实现会话、参考空间与立体呈现。

**操作**：拖拽环视 · 滚轮变焦 · `WASD` 沿导轨移动 · 靠近热点自动弹出展签（可点击来源链接）

## 4. 无障碍

- 跳转链接、可见焦点环、全部交互元素可键盘操作。
- 展厅提供**纯文本 2D 目录**：展项与全部史料条目无需图形界面即可阅读。
- 节奏轨道使用**形状标识**而非仅靠颜色区分；提供高对比、减少动效、视觉节拍（静音替代）三组开关。
- 判定校准滑块（±200 ms）用于适配不同设备的音频延迟。
- 设置、成绩与进度全部保存在本机，不上传任何数据。

## 5. 限制与已知取舍

1. **曲目为程序化生成**：谱面即乐谱，结构简洁但视听精确对齐；不是录音棚作品，也不追求完整曲式。
2. **提示基于推荐解法**：若玩家自行找到另一组解，提示可能指向非唯一解（UI 已注明）。
3. **光环台不是 WebXR 应用**：不实现立体渲染与手柄追踪，如实标注为桌面演示。
4. **时间轴为代表性选样**：24 条覆盖 2011–2026，不宣称穷尽该时代。
5. 本展厅视觉体系与母馆（06）协调但**独立命名与配色**，便于母站区分。
6. 未使用任何图片素材；页面图形全部程序化绘制，因此无第三方图片授权问题。
