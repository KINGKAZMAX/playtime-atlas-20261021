# 折光纪 · 当代可玩展厅 / PRISM ERA

> 回响电玩馆（PLAYTIME ATLAS）· **modern（2015–2026）时代展厅**
> 三件可玩展品：节奏反应 · 空间解谜 · 桌面端沉浸观景台

本目录是一个**独立、可静态部署**的子展厅。全部作品名、文案、音乐、视觉、关卡均为原创；
参考的是公开作品成熟的机制与品质标准，**不声称原创任何参考作品**，不使用任何未授权 ROM、
商业游戏资源或品牌视觉。

## 1. 快速开始

```bash
cd 12-era-modern
npm install          # 依赖全部本地安装，运行期零 CDN
npm run dev          # 开发服务器  http://127.0.0.1:4332
npm run build        # 静态产物   →  dist/
npm run preview      # 预览产物   http://127.0.0.1:4332
npm run start        # 一键：安装依赖 + 启动开发服务器
```

自检命令：

```bash
node scripts/test-levels.mjs   # 关卡自检：验证 4 关均可用作者解法点亮全部接收环
node scripts/check-i18n.mjs    # 文案骨架自检：zh / en 键集合一致、无空文案、占位符对齐
```

**部署形态**：`vite.config.js` 中 `base: './'` + 哈希路由（`#/pulse` 等），
因此 `dist/` 可以直接放在任意静态目录或子路径下（GitHub Pages 的 `/<repo>/<subdir>/` 亦可），
**无需服务端重写规则**。字体在产物内以**相对路径**引用（`url(./space-grotesk-latin-<hash>.woff2)`），
子路径下同样 200。

## 2. 三件展品

### 2.1 《脉冲走廊 / PULSE CORRIDOR》— 节奏反应

四轨光带从远处滑来，节拍与手指对撞。三首曲目全部由 WebAudio **实时合成**（无音频文件），
**谱面即乐谱**：每个音符既是判定点也是主旋律的一个音，因此视听天然对齐、不会漂移。

| 曲目 | BPM | 难度 | 特点 |
| --- | --- | --- | --- |
| 启明 / FIRST LIGHT | 100 | 入门 | 四分音符双向级进 |
| 潮汐 / TIDE GLASS | 124 | 进阶 | 切分与八分音跑动 |
| 棱镜风暴 / PRISM STORM | 150 | 挑战 | 十六分音簇 + 反应事件 |

**三种模式**
- **谱面模式 CHART**：跟随主旋律敲击轨道，判定准度、连击与评级（S/A/B/C/D）。
- **反应训练 REACTION**：只做反应，统计中位 / 最快 / 最慢反应时。
- **混合模式 HYBRID**：谱面中穿插「应答靶」（出现后必须按对应轨道）与「禁触靶」（不得按下）。

**静音视觉替代（硬性要求，已实现）**
- 开启「视觉节拍模式」后**完全不产生任何声音**：不创建 AudioContext，节拍改由
  **收缩节拍环 + 下行节拍光带 + 顶部拍点标尺 + 轨道行亮度脉冲**表达。
- 游戏时钟统一走 `performance.now()`，音频只是可选呈现层，
  因此**静音模式与有声模式的判定精度完全一致**（验收记录见 `QA.md`）。
- 轨道用**形状标识**（◆ ● ▲ ■）区分，兼容色觉障碍；另提供高对比与减少动效开关。

**操作**：`D F J K` / `← ↓ ↑ →` / 触屏点按 · `Esc` 暂停 · `R` 重开 · `M` 静音（设置面板内）

### 2.2 《折光阁 / PRISM ATRIUM》— 空间解谜

等距 3D 玻璃中庭。转动反光板，让白光在立柱之间折返、劈成青与品红，分别落进接收环。

**元件与规则（原创）**

| 元件 | 作用 |
| --- | --- |
| 光源塔 emitter | 定向发射指定颜色的光 |
| 反光板 mirror | 两向反射（`/` 与 `\`），可旋转 |
| 分光镜 splitter | 一束变两束：直行 + 指定方向分叉 |
| 色散棱镜 dispersion | 白光裂成青 + 品红，分别射向两个方向 |
| 接收环 receiver | **颜色必须匹配**才会点亮；不匹配会给出「色不符」提示 |
| 光栅门 gate | 挡光挡人，由余辉压板供电 |
| 余辉压板 plate | 踩下后维持 15 秒开启（制造时间压力） |
| 移动浮台 platform | 往返移动并载行玩家 |
| 光点 mote | 可选收集，影响星级 |

**四个关卡**

| 关 | 名称 | 机制重点 | 接收环 |
| --- | --- | --- | --- |
| LV1 | 回廊 CORRIDOR | 移动 + 旋转反光板 | 1 |
| LV2 | 分流 FORK | 色散、分光、颜色匹配 | 3 |
| LV3 | 时序 CADENCE | 光栅门 + 余辉压板 + 移动浮台 | 1 |
| LV4 | 合奏 CHORUS | 三光源 / 三棱镜 / 门与压板 | 4 |

**进度与工具**：通关记录、最佳用时、星级、光点数量自动存本机（localStorage）；
可随时 **撤销 / 提示 / 重置**。提示基于关卡作者预设的推荐朝向（UI 已注明这一点）。

**操作**：`WASD` / 方向键移动 · 点击元件或 `E` 旋转 · `Tab` 切换目标 · 拖拽旋转视角 · 滚轮缩放

### 2.3 《光环台 / HALO DECK》— 沉浸展项（桌面交互演示）

> ⚠️ **诚实声明**
> 本展项是**桌面端交互演示**：用鼠标拖拽与键盘模拟头部转动，
> **未接入 WebXR、不支持 VR 头显**，没有立体渲染，也没有手柄追踪。
> 它演示的是「沉浸式展陈的交互模型」，**不是** VR 应用。
>
> 展台提供「检测本机 WebXR 沉浸式 VR 支持」按钮，结果直接来自浏览器
> `navigator.xr.isSessionSupported('immersive-vr')` 的真实返回值，与本展项的实现无关。
> 真正的设备支持需要按 [W3C WebXR 规范](https://www.w3.org/TR/webxr/) 实现会话、参考空间与立体呈现。

**操作**：拖拽环视 · 滚轮变焦 · `WASD` 沿导轨移动 · 靠近热点自动弹出展签（可点击来源链接）

## 3. 视觉规范与改版

本厅的视觉语言已按 **`16-design-system`（余晖设计系统 v1.0）** 统一。
按 `MIGRATION-NOTES.md` §1 的接入四步，本目录采用**路径 C（引入令牌层 + 组件层）**：

| 接入步骤 | 本目录的落点 |
| --- | --- |
| ① 令牌层 | `public/assets/ds/tokens.css` = 16 号 `src/tokens.css` 的**原样副本**（仅加来源说明头，取值零改动）。它是本目录 `--ds-*` 取值的**唯一声明处** |
| ② 字体 | `public/assets/ds/fonts/` = 16 号 `fonts/` 的原样副本（5 款 woff2 + 5 份 OFL 全文 + FONT-MANIFEST），由 `assets/ds/fonts/fonts.css` 以**同目录相对路径**引用 |
| ③ 换外壳 | 顶栏 / 页脚 / 封面 / 作品卡 / 控件 / 画布框 / HUD 等在**既有类名之上叠加** `.ds-*` 类（不删除既有 CSS，§10 红线） |
| ④ 注入基准路径 | `index.html` 注入 `<style>:root{--ds-base:"/playtime-atlas-20261021/";}</style>` |

| 维度 | 现状 |
| --- | --- |
| 令牌 | 全部 `--ds-*` 取值来自 `public/assets/ds/tokens.css`（与 `design-tokens.json` **逐名相等**，已实测 121 项零差异）；本目录自有层只保留**语义别名**（`--ink-900: var(--ds-bg)`）与**玩法语义色** |
| 字体 | Space Grotesk（展示）/ Inter（正文）/ Space Mono（等宽）+ Noto Sans SC 子集（中文**最后兜底**），全部 **OFL 1.1 自托管**于 `assets/ds/fonts/`；中文以系统 CJK 栈为主 |
| 主题 | 外壳为**浅色**（暖白纸 + 朱砂强调），`<html data-ds-theme="light">` 固定，不跟随系统深色；三个可玩展项的**画布与 HUD** 单独以 `data-ds-theme="dark"` 取深色令牌，保证 HUD 对比度 ≥ 4.5:1 |
| 强调色 | 全站**唯一强调色** `--ds-accent`（朱砂 `#B4432B`）：主 CTA、当前选中、焦点环、关键数据高亮 |
| 画布 | **游戏画面内部配色一律不动**（16 的红线 K.1）：光束、判定色、接收环色、热点色仍与改版前一致，避免玩家读错元素 |
| 动效 | 统一 `--ds-ease-out` / `--ds-dur-base`；`prefers-reduced-motion`（系统）与 `[data-rm="reduce"]`（设置开关）**两条路径**均把时长归 `1ms`、位移与模糊归零，**但节拍提示、线索与控件全部保留** |
| 中文排版 | 字距归零、正文行高 1.85（`src/styles/cjk.css`，**最后加载**以压过既有类名）；CJK 字体栈顺序按规范（完整系统族在前、有限子集在后） |
| 子路径 | `base: './'`；`assets/ds/**` 与 `assets/*.woff2` 全部**相对路径**，无绝对根路径，可部署于任意子路径 |

**字重的显式预加载**：浏览器只在页面**真正用到**某个字重时才去取对应的字体文件。
本厅正文只用 Space Mono 400，其 700 字面默认不会被取回；而 Canvas 2D 的 `ctx.font`
是同步生效的，取不到字体不会等待而是**静默回落**系统等宽字体（肉眼几乎无差别，
但 `Space Mono` 实际并未生效）。因此启动时与《脉冲走廊》开赛前都会调用
`preloadFonts()`（`src/core/fonts.js`）显式加载四个必需字重；
Canvas 的字体族名也改为从 `--ds-font-display` / `--ds-font-mono` 令牌读取，不再写死。
详见 `QA.md` §1.5.5 与 §8 缺陷 13–15。

**改版前后的取舍**：改版只换**视觉语言**（色板 / 字体 / 间距 / 圆角 / 动效 / 外壳形态），
**作品名、文案、音乐、关卡、史料与玩法一律未改**。改版清单见 `RESTYLE-INVENTORY.md`。

### 3.1 可观测状态与自动化契约

页面在 `window.__eraGame` 上暴露**一个**只读状态对象（`state` / `route` / `chapter` / `score` / `player` / `extra`），
供自动化验收比对按键是否真的驱动了游戏。它**只读地反映真实运行状态，不参与任何玩法逻辑**，
也不会影响可玩性；同时也是调试入口。

为便于自动化验收，界面元素上保留了一组**契约属性**：

| 属性 | 位置 | 含义 |
| --- | --- | --- |
| `data-exhibit="pulse\|atrium\|halo"` | 展厅 hero CTA 与展项卡 | 展品入口 |
| `data-control="start\|pause\|restart"` | 脉冲走廊 | 开始 / 暂停 / 重开 |
| `data-control="undo\|hint\|restart\|view"` | 折光阁 | 解谜操作 |
| `data-control="detect-vr"` | 光环台 | WebXR 真实检测入口 |
| `data-game-root` + `tabindex="0"` | 三个展项舞台 + 脉冲选单 | 游戏面与键盘焦点作用域 |

**键盘焦点作用域**：游戏按键**只在游戏区持有焦点时**才被消费（未聚焦不劫持键盘，
iframe 嵌入母站时不会干扰主站）；进入展项即自动聚焦画面，HUD 提示「点击画面可重新聚焦」。

### 3.2 文案骨架（zh/en）

`src/core/i18n/` 已备好 **162 个键**的中英文案骨架（`zh.js` / `en.js` / `index.js`），
`scripts/check-i18n.mjs` 强制校验键集合一致、无空文案、占位符对齐。

## 5. 无障碍

- 跳转链接、可见焦点环（2px 背景环 + 2px 强调色环，任何状态不得移除）、全部交互元素可键盘操作。
- 展厅提供**纯文本 2D 目录**：展项与全部史料条目无需图形界面即可阅读。
- 节奏轨道使用**形状标识**而非仅靠颜色区分；提供高对比、减少动效、视觉节拍（静音替代）三组开关。
- 判定校准滑块（±200 ms）用于适配不同设备的音频延迟。
- 设置、成绩与进度全部保存在本机，不上传任何数据。
- 关键文本对比度实测 ≥ 4.68:1（正文门槛 4.5:1），触摸目标 ≥ 24px（实测最小 32px）。

## 6. 限制与已知取舍

1. **曲目为程序化生成**：谱面即乐谱，结构简洁但视听精确对齐；不是录音棚作品，也不追求完整曲式。
2. **提示基于推荐解法**：若玩家自行找到另一组解，提示可能指向非唯一解（UI 已注明）。
3. **光环台不是 WebXR 应用**：不实现立体渲染与手柄追踪，如实标注为桌面演示。
4. **时间轴为代表性选样**：24 条覆盖 2011–2026，不宣称穷尽该时代。
5. 未使用任何图片素材；页面图形全部程序化绘制，因此无第三方图片授权问题。
6. **本目录的 `--ds-*` 取值只有一处声明**：即 `public/assets/ds/tokens.css`
   （16-design-system `src/tokens.css` 的原样副本）。本目录自有的 `src/styles/tokens.css`
   **只声明语义别名**（`--ink-900: var(--ds-bg)`）与玩法语义色，**不重新定义任何 `--ds-*` 取值**
   （MIGRATION-NOTES §0 风险 B）。「高对比」开关因此走 `--hc-*` 间接层，而不是改写 `--ds-*`。
7. **中文以系统字体栈为主**：汉字由 PingFang SC / 微软雅黑 / Hiragino Sans GB /
   Source Han Sans SC 等**系统族**渲染；16 号交付的 `Noto Sans SC` 子集已随包引入，
   但只排在系统栈**之后**作为最后兜底（该子集覆盖有限，覆盖完整的族必须在前，
   否则会出现混排基线错位）。因此跨设备汉字字形一致性无保证。
8. **`--ds-base` 已按规范注入为 `/playtime-atlas-20261021/`**，但本厅产物**自包含**、
   不引用任何站点级资源；自身资源一律相对路径（`base: './'`），可部署于**任意**子路径。
9. **英文版尚未启用**：文案骨架已就绪，但界面仍为中文；内容型文案（史料、关卡叙事、热点长文）不在骨架内。
10. **「唯一强调色」的一处自觉偏离**：三个展项与时间轴年代保留了各自的**身份色**（装饰 / 身份语义，
    非交互语义），以区分展项并与画布内的玩法色保持一致；交互强调（CTA / 当前项 / 焦点环）仍只有一个朱砂色。
11. **设计系统组件层的两处取值冲突已在本地就地校正**（不修改 16 号副本）：
    ① `.ds-btn` 默认 `--ds-btn-h: var(--ds-space-10)` = 128px，本目录覆盖为 44px；
    ② `.ds-input` 的 `appearance:none` 会抹掉 range 滑块本体，滑杆保留浏览器原生外观。
    校正只动**普通几何属性**（`height` / `appearance`），**不在自有层重设任何 `--ds-*` 取值** ——
    本目录自有 CSS 的 `--ds-*` 取值声明数为 **0**。
12. **`.ds-rail` / `.ds-indicator` / `.ds-diagram` 按「映射既有组件」的方式落地**：
    年份跳转轴、分区进度指示器、折光阁图例面板。设计系统另有「固定导航轨」
    （`.ds-rail` 的 `position:fixed` 默认形态），本目录未采用——固定轨会与 1280px 内容列重叠，
    改用其 `--horizontal` 变体作为面板内的静态横条。
13. 改版的**可玩性红线**（画布内配色不动、HUD 对比度优先）已守住，但**视觉统一度**由本目录自评，
    仍需 13 号的「风格一致性」验收独立判定。
14. **设计系统机械验收只覆盖 Chrome**：`scripts/verify-ds.mjs` 使用本机 Chrome 原生 CDP，

    另：16 号 `verify-preview.mjs` 在本机高负载下会因截图超时误报失败
    （放宽超时后全绿），本目录的 `verify-ds.mjs` 走同一 CDP 路径但不受影响。
