## 5. 玩法要求

### 5.0 通用（两游戏都必须满足）

- [ ] **开始 / 暂停 / 重开 / 计分 / 难度** 齐备
- [ ] **触屏可玩**（移动端完整可玩，不只是能看）
- [ ] **键盘只在游戏获得焦点时生效**（`focus` 门控；失焦时给出提示，不劫持页面滚动/快捷键）
- [ ] iframe 内可独立运行（不跳出父页面、不依赖父页面脚本）
- [ ] 窗口失焦 / 切后台自动暂停
- [ ] 程序化音效（WebAudio），首次用户手势后启动，可静音
- [ ] 最高分 / 设置写入 `localStorage`
- [ ] 固定步长物理（帧率无关），`requestAnimationFrame` 渲染

### 5.1 游戏一 — 辉点对拉 / LUMEN RALLY

双人 / AI 光点球。机制谱系：Tennis for Two → Pong。

- 光点球带**余辉拖尾**（呼应 Tennis for Two 的亮点拖影）
- **蓄力重击**：按住蓄力 → 回球加速并带「重击」窗口，窗口内得分记 +2
- **偏心回弹**：击球点偏移 → 改变出射角与旋转
- 回合数提升球速（有上限）
- 模式：`1P vs AI`（三档难度：初辉 / 稳流 / 锐锋）、`2P 本地双人`
- 比分先到 **7** 结束；发球倒计时；胜负结算与再战

### 5.2 游戏二 — 引力双星 / GRAVITY DUO

轨道引力对决。机制谱系：Spacewar!（引力井）→ Asteroids（矢量飞船操作）。

- 双飞船受**中央核心引力**与**互相引力**作用，旋转 + 推进产生真实轨道
- 每艘飞船留下**光迹尾迹**；撞到对手尾迹 → 灼伤扣血 + 得分
- **相位脉冲**：有限次数的冲击波，炸毁对手尾迹并推挤对手（反制手段）
- 光能（血量）、燃料、脉冲充能；积分：灼伤 +3 / 炸毁尾迹 +1 / 每 10 秒存活 +1
- 模式：`1P vs AI`（三档难度：微调 AI 反应 / 核心引力 / 尾迹长度）、`2P 本地双人`
