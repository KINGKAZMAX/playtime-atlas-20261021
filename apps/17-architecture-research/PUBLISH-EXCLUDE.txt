# PUBLISH-EXCLUDE — 发布前必须排除的路径（17-architecture-research）
#
# 供 14-publish 机械拦截用。路径均相对 17-architecture-research/ 根目录。
# 判定规则：只要最终 dist/ 树中出现下列任一路径，发布即应中止。
#
# 背景：14-publish/release/scripts/build.mjs 的静态分支中
#   keepDirs = ['data', 'public', 'assets', 'exhibits', 'models', 'fonts']
# 其余目录默认即被排除（不在 keepDirs 内），但 `data` **在白名单内**，
# 因此 data/ 必须由发布方显式排除，不能依赖默认行为。
# 另：keepExts 包含 '.json'，故根目录下的 .json 台账若不加限制也会被复制。
#
# 判定方式（14 侧建议）：
#   1) work.build.exclude 追加 'data'（目录名，与 build.mjs 第 231-236 行的排除逻辑一致）；
#   2) 或在发布流水线加一道断言：dist/ 内不得出现本文件列出的任何路径。
#
# 语义说明：
#   EXCLUDE_DIR   整个目录排除
#   EXCLUDE_FILE  单个文件排除
#   EXCLUDE_GLOB  路径前缀 / 模式排除
