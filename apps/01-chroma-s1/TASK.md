## 3. 作品定义（原创改编）

**作品名：CHROMA S1 · 千色仪**
**一句话：把颜色，量出来。**
**定位：** 便携式光谱色度仪的产品发布页。

| 维度 | 决策 |
|---|---|
| 形态 | 口袋级测量仪器（非游戏机、非消费电子） |
| 色彩系统 | 冷黑仪表底 + 琥珀橙信号色 + 电光青 + 紫罗兰 |
| 字体系统 | 拉丁与数字用 Martian Mono / Space Grotesk / JetBrains Mono；中文用系统栈 |
| 布局 | 左侧固定章节索引轨 + 非对称双栏 + 仪表读数区 |
| 核心交互 | 可交互光谱实验室、样本库联动、三维拆解视图、规格矩阵、FAQ、预约表单 |
| 数据真实性 | 曲线与 ΔE00 由 CIE 1931 配色函数积分 + CIEDE2000 实时算出，不是贴图也不是硬编码 |
