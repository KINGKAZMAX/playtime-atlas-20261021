## 7. D1「文字重叠遮挡」自查记录（配合 13-qa-curation 复核）

**脚本**：
- `qa/d1-overlap.mjs` —— 与 13 同判定口径（字形行盒求交 + 祖先 overflow 裁剪），
  测量函数抽在 `qa/lib/overlap-measure.mjs` 供两个脚本共用；结果存档
  `qa/d1-final.json`（多滚动位置）、`qa/d1-scroll0.json`（13 的测量位置）。
- `qa/overlap-audit.mjs` —— 早期自建审计（含 `elementFromPoint()` 命中点判定），
  结果存档 `qa/overlap-report.json`。
- `qa/verify.mjs` —— 新增 10 条结构性断言（桌面 + 移动各一遍）。

**目视**：`screenshots/12-full-page-desktop.png`（1440×8548）、
`screenshots/13-full-page-mobile.png`（390×10525）（整页逐屏，2026-10-21 22:37 重拍）

### 7.1 判定口径

1. 只比较「自身直接含文字」的元素，父子嵌套单独归类；
2. 判断固定层查**祖先链**（`position: fixed` 的顶栏，其子元素 `position` 是 `static`）；
3. 相交区取 9 个采样点，用 `document.elementFromPoint()` 取最上层绘制元素：
   取不到该文本元素 → 被祖先 `overflow` 裁剪 → **不可见，不算遮挡**；
4. 文字盒按 `Range.getClientRects()` 的**字形行盒**求交（与 13 的 D1 一致），
   被祖先 `overflow:hidden|clip` 裁掉的行不算绘制。

### 7.2 结果（2026-10-21 本轮修复后）

| 口径 | 桌面 1440×900 | 移动 390×844 |
|---|---|---|
| 13 的检测器 + 13 的测量位置（滚动 0） | **0 对** | **0 对** |
| 13 的检测器 + 多滚动位置采样（20 / 26 个位置） | 真实压盖 **0 对**（固定外壳层 4 对） | 真实压盖 **0 对**（固定外壳层 41 对） |
| 结构性断言（`qa/verify.mjs`） | 5 条全过 | 5 条全过 |

修前对照（同一套脚本、同一台机器）：

| 口径 | 修前 | 修后 |
|---|---|---|
| 13 的检测器 + 滚动 0 | desktop 0 / mobile 1（`stage__hint`×`readout__k` 85%，559px²，与 13 `issues.json` 登记一致） | desktop **0** / mobile **0** |
| 多滚动位置采样 | desktop 8 / mobile 41（含折叠区越界 8 / 19 对） | desktop **0** / mobile **0** |

「固定外壳层」= 粘性顶栏（DS §4.2 规定 `position: sticky` + `backdrop-filter: blur(12px)`）
及其内的导航项、章节指示、CTA 压在滚动内容上的几何相交：被盖住的正文不构成两段文字互相压盖，
13 的检测器在滚动位置 0 也测不到，单独归为一类、不计入压盖数。

### 7.3 本轮修掉的三类根因

1. **折叠面板越界**：`grid-template-rows: 0fr→1fr` + `overflow:hidden` 的折叠写法，
   折叠态面板盒高 0 而内部 `p` 文字盒仍是自然高度（实测 81.19px），整体越出面板压到下一行标题。
   → 改为折叠态 `display:none`（内容完全不在文档流），展开态回到正常流，动画改为纯透明度入场。
2. **移动端章节指示是固定浮层**（`position:fixed` + `transform:translateX(-50%)` 压在正文上）。
   → 移入顶栏，成为顶栏内的正常流元素。
3. **画布操作提示与画布 HUD 面板相交**（窄屏画布 153px 高 < 面板 170.6px，面板还被
   `.stage` 的 `overflow:hidden` 裁掉 ΔE00 行）。→ 提示行移出画布进正常流；
   面板在窄屏收紧、让出手机宽度下的色块，保证完整可见。
