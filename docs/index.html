03 作品与资产 WORKS & ASSETS

探索可玩的作品、年代展厅与美术资产。

独立作品

四件可独立游玩的完整作品：掌机落地页、程序化生成的机械甲壳生物查看器、织造调度台与 6 自由度驾驶模拟。机制、界面与玩法规则均为我重新设计实现。

年代展厅

五个独立可玩的年代展厅，覆盖早期电子实验、街机、16 位主机、网络时代与现代 VR 主题。展厅内的历史条目属于第三方史料整理，展厅玩法为原创演绎。

原创美术资产

深墨蓝 + 暖纸白 + 信号橙的视觉方案，自托管字体、图标、年代海报、封面、展柜与跨时代硬件简化模型，可预览并随作品一起使用。

可下载产物

部分作品提供可下载产物（例如可导出的 3D 模型），在各作品详情页内直接取得；其余作品以在线体验为主。

零依赖

全部几何、贴图、图标、封面与音效由代码生成或使用可再分发的开源字体。作品运行时自包含、资产本地化，不请求外部接口，展品图像不使用商业游戏截帧。

试玩说明

作品在站内以 iframe 嵌入运行。首次点击画面后才会激活键盘输入与指针锁定；部分驾驶类作品在嵌套页面中可能被浏览器限制，必要时请「独立窗口打开」。

部署与构建

本站由 GitHub Actions 自动构建并发布到 GitHub Pages。仓库保存全部源码与构建脚本；单件构建失败不会阻断其余作品，并会回退到上一版已验证产物。
